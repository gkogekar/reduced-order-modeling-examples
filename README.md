# Reduced Order Modeling Examples (CFD & Transport Systems)

This repository contains a collection of Reduced Order Modeling (ROM) case studies applied to fluid dynamics and transport problems. The goal is to demonstrate how high-dimensional CFD solutions can be efficiently approximated using low-dimensional representations while retaining key physical features.

## Case Studies
### 1. Boundary Layer Flow
- ROM reconstruction of velocity field in a boundary layer
- Analysis of dominant flow structures
- Energy decay across POD modes
- Reconstruction error vs. number of modes

(Additional examples will be added as new systems are explored.)
